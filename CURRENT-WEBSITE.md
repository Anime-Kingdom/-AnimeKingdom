# Current Anime Kingdom website

This replacement contains the current Vite storefront with its existing design and colors.

Included: homepage artwork and animations; product images and details; cart and wishlist; delivery address form; COD and UPI checkout with QR, UTR and screenshot; custom figure form with Instagram ID, reference upload, size, pose and finish; Instagram and WhatsApp links; Supabase submission integration.

Run `npm ci`, then `npm run dev`. Build with `npm run build` and host `dist`. Customer submissions remain in Supabase and are not repository files. UPI payment verification is manual.
